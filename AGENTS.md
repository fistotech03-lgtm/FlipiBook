# Agent Guidelines & Rules

## Strict Git Command Approval Rule
**NEVER run any git write, restore, commit, branch, or push operations without explicit user approval in chat.**
This includes but is not limited to:
- `git restore`
- `git commit`
- `git push`
- `git checkout --`
- `git reset`
- `git merge`
- `git rebase`

Always ask the user for permission explicitly before running any of the above commands.

## Performance & Speed Rule
- Execute updates directly and quickly without unnecessary delays or prolonged multi-step rabbit holes.
- Keep implementation focused, concise, and swift.
